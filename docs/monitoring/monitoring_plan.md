# Monitoring plan

## Mục tiêu

Định nghĩa signal, owner, cadence, threshold, escalation và action.

## Khái niệm chính

Plan gồm data quality, drift, performance, calibration, fairness, operations, incidents, retraining criteria và model retirement.



## Ví dụ trong credit scoring

Alert PSI chỉ mở investigation; rollback/retrain cần decision rule và phê duyệt.

## Điều cần kiểm tra trong project

- [ ] Xác nhận reference window và label maturity.
- [ ] Gắn owner, cadence, threshold và escalation.
- [ ] Lưu monitoring artifact đã khử định danh.
