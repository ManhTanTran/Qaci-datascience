# Decision records

## Mục tiêu

Quản lý quyết định kiến trúc/modeling có bối cảnh và hệ quả.

## Khái niệm chính

ADR gồm status, context, decision, alternatives, consequences, evidence, owner và review date. Không chỉnh lịch sử ADR accepted; tạo ADR mới supersede.



## Ví dụ trong credit scoring

Thay đổi primary metric cần ADR thay vì sửa ngầm cấu hình.

## Điều cần kiểm tra trong project

- [ ] Ghi owner, ngày và trạng thái.
- [ ] Liên kết evidence/experiment.
- [ ] Tạo ADR mới khi supersede quyết định accepted.
