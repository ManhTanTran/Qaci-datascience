# ADR-0001: Cấu trúc project

## Mục tiêu

Ghi nhận cấu trúc docs/catalogs làm knowledge base.

## Khái niệm chính

Quyết định: tài liệu theo domain và registry YAML ở `catalogs/`; source-of-truth và card phải liên kết hai chiều.



## Ví dụ trong credit scoring

Thêm dataset đòi hỏi registry entry và dataset card.

## Điều cần kiểm tra trong project

- [ ] Ghi owner, ngày và trạng thái.
- [ ] Liên kết evidence/experiment.
- [ ] Tạo ADR mới khi supersede quyết định accepted.
